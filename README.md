## 🔍 Project Overview
This project transforms raw multi-platform social data into actionable marketing insights. It covers high-level executive KPIs down to qualitative text diagnostics like tracking sentiment shifts and community toxicity.

### Key Focus Areas:
* **Campaign Velocity:** Tracking engagement rates and total impressions across distinct marketing phases.
* **Audience Mindset:** Mapping emotional responses (e.g., Excited, Confused, Angry) against individual brands.
* **Algorithmic Optimization:** Determining peak engagement windows using calculated temporal metrics.

---

## 🛠️ Data Architecture & Transformations
The underlying data is sourced from **Social Media Engagement Dataset.xlsx**. Key engineering steps completed directly within the model include:
1. **Temporal Splitting:** Calculated explicit `Post Date` and `Post Hour` granularities from raw timestamps using custom DAX expressions.
2. **Explicit Measures:** Standardized calculation logic away from implicit columns using explicit DAX metrics for `Total Interactions` and weighted `Average Engagement Rates`.

---

## 📈 Key Insights Uncovered
* **Platform Dominance:** Visualized channel distribution highlights which platforms drive absolute volume versus relative engagement efficiency.
* **Sentiment Clusters:** Identified clear categorical patterns mapping toxic comments versus hyper-positive brand promoters.
